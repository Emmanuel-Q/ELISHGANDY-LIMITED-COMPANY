# Launch checklist

## Content

- [ ] Approve company overview, mission, vision, values, and service descriptions.
- [ ] Replace public contact placeholders with verified details.
- [ ] Confirm production domain and public website URL.
- [ ] Supply and approve the real capability statement before adding a download.
- [ ] Review all photographs and ensure none imply unverified company work.
- [ ] Approve any additional project, people, certification, or registration evidence.

## Quality and accessibility

- [ ] Review all pages on mobile, tablet, and desktop.
- [ ] Test keyboard access, focus visibility, menu behavior, and form labels.
- [ ] Test with reduced motion enabled.
- [ ] Check contrast and heading order.
- [ ] Validate HTML, links, images, JavaScript, and responsive layout.
- [ ] Run Lighthouse/PageSpeed on the deployed site and record actual results.

## SEO and security

- [ ] Replace canonical/Open Graph placeholders with the verified domain.
- [ ] Populate the sitemap and robots sitemap URL.
- [ ] Check page titles, descriptions, structured data, and social previews.
- [ ] Confirm no secrets or private company documents are public.
- [ ] Confirm HTTPS and approved preview privacy.

## Deployment

- [ ] Verify UltraHost SSH/SFTP settings and exact paths.
- [ ] Configure protected GitHub secrets and separate preview/production targets.
- [ ] Confirm backups, rollback, and deployment verification steps.
- [ ] Approve the final production release.

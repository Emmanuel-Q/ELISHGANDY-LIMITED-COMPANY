# SEO

Each HTML page has a distinct title and description, a canonical placeholder, Open Graph metadata, semantic headings, and crawlable internal links. The homepage contains Organization and WebSite JSON-LD using only approved company facts.

`sitemap.xml` and `robots.txt` are present. Add absolute page URLs and the sitemap location after the production domain is confirmed. Check canonical and social preview URLs before launch. Do not add fabricated social profiles, contact points, reviews, ratings, coordinates, or local business hours.

Service pages use descriptive titles and text based on the approved division descriptions. Do not keyword-stuff. Verify the deployed URL set and sitemap using the final domain.
